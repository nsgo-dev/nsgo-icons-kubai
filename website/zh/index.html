NSGo 的 Kubai Icons

2,945 个以强调色的色调分层绘制、带渐变、阴影和角标，悬停时会动的图标。为 NSGo 原生应用预先编译：不运行 JavaScript，动画由平台在其帧时钟上播放。

开始使用 GitHub

原生，而且会动

上游用 JavaScript 绘制每个图标。本库在构建时运行一次这些代码，并保留它画出的结果。

分层着色

每个图标都可以指定强调色和样式，角标有自己的色调。

悬停即动

每个图标由一个动画值驱动，动画在平台的帧时钟上运行。

不需要 JavaScript

图标是画布操作和动画轨道，NSGo 的每个后端都能绘制。

用多少带多少

每个图标一个访问函数，没有注册表：应用只链接它调用的图标。

开始使用

使用 Go 1.26 或更高版本，把本库加入 NSGo 应用。

go get github.com/oneo-me/nsgo-icons-kubai
import kubai "github.com/oneo-me/nsgo-icons-kubai"

kubai.Icon{
	Symbol: kubai.FolderPlus(),
	Size:   32,
	Label:  "Folder plus",
}

查找图标

gallery 可以按名称搜索所有图标，并给出按你设置的大小、强调色和样式绘制所选图标的代码，可直接复制。检出本仓库后运行：

git clone https://github.com/oneo-me/nsgo-icons-kubai
cd nsgo-icons-kubai
go tool nsgo dev examples/gallery
